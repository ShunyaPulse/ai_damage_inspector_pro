# AI Damage Inspector Pro

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://ai-damage-inspector-pro.vercel.app)
[![Next.js](https://img.shields.io/badge/Next.js-16-black?logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue?logo=typescript)](https://www.typescriptlang.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4-38B2AC?logo=tailwind-css)](https://tailwindcss.com/)

An AI-assisted visual damage inspection and cost-estimation platform built with Next.js, React, and TypeScript. Users can upload multi-angle damage photographs, run automated condition assessments, and instantly export professional PDF inspection reports.

---

## ✨ Features

- **Multi-Angle Visual Uploads**: Drag-and-drop or select multiple photos of damaged items (vehicles, property, hardware).
- **Automated Damage Assessment**: Analyzes visual inputs, assigns severity ratings, and provides damage classifications.
- **Repair Cost Estimator**: Calculates itemized repair and replacement cost approximations.
- **Client-Side History**: Automatically archives past assessments locally in browser storage for quick review.
- **Instant PDF Export**: Generates clean, downloadable inspection reports using `jsPDF`.
- **Modern Responsive UI**: Clean interface built with Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **PDF Generation**: jsPDF
- **Deployment**: Vercel

## 🚀 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/ShunyaPulse/ai_damage_inspector_pro.git
cd ai_damage_inspector_pro
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
